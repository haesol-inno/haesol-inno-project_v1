# GenAI 기초: LLM 기반 업무 자동화 — 학원 학부모 문의 응대 답변 초안

학원 상담 실장이 반복적으로 처리하는 **학부모 문의(수강료·환불·보강·할인)**에 대해,
운영 정책 시트에 근거한 답변 초안을 생성하는 LLM 업무 자동화 과제입니다.
3종 모델을 평가 축 기반으로 비교해 모델을 선정하고, 시스템 프롬프트를 v1→v3로 개선했으며,
환각 검증·10턴 이상 대화 검증·자동 검증 스크립트(보너스)까지 포함했습니다.

## 폴더 구조

```
.

├── 02_prompt_design.md          # 시스템/유저/입력 분리, 페르소나, v1→v2→v3, 시스템 프롬프트, Few-shot 3종
├── 03_model_comparison.md       # 3종 모델 비교 (평가 축 5개, 가중치, 점수, 근거), 선정 이유
├── 04_hallucination_test.md     # 환각 정의, Pass-A/B·Fail 기준, 검증 질문 8개 × 3모델, 원인 분석
├── 05_conversation_log.md       # 16턴 대화 로그 (조건 변경 5회, 환각 유도 1회)

├── 07_bonus.md                  # 보너스: 답변 초안 자동 검증기 설명
├── templates/

│   └── policy_sheet.md          # 운영 정책 시트 (과제용 가상 학원)
└── bonus/
    ├── validate_output.py       # 금액/비율 환각·형식·글자 수 자동 검사

```

## 빠른 사용법

1. `02_prompt_design.md` 3장의 시스템 프롬프트(+ Few-shot 3개)를 모델의 시스템 프롬프트/프로젝트 지침에 붙여 넣는다.
2. `templates/input_template.md`를 복사해 문의 내용을 채우고, `[운영 정책]`에 `templates/policy_sheet.md`를 붙여 넣는다.
3. 생성된 답변을 파일로 저장해 검사한다.
   ```bash
   python3 bonus/validate_output.py answer.md            # 카톡
   python3 bonus/validate_output.py answer.md --sms      # 문자 90자
   ```
4. `3) 확인 필요 항목`을 담당자가 확인한 뒤 사람이 발송한다.

## 주요 학습 내용

- LLM은 사실을 조회하지 않고 확률적으로 다음 토큰을 생성하므로, **정답이 정해진 영역의 근거 불일치**만을 환각으로 정의해야 측정·통제할 수 있다.
- 정책 수치를 모델 기억이 아닌 **입력(정책 시트)**으로 주고, 출력에서 확정/미확정을 물리적으로 분리하면 환각을 크게 줄일 수 있다. 그러나 0이 되지는 않으므로 자동 검사 + 사람 검토가 필요하다.
- 모델 선정은 "가장 좋아 보이는 모델"이 아니라 **과업의 핵심 리스크에 가중치를 둔 평가 축**으로 결정해야 하며, 프롬프트로 보완 가능한 약점(톤)과 어려운 약점(환각 성향)을 구분해야 한다.
- 긴 대화에서는 매 턴 **상태 블록**을 갱신하게 하면 조건 변경이 안정적으로 유지된다.
